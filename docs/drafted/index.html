dstory.draft() profiled mix.csv, picked the scenes, mapped the columns onto cookbook recipes and wrote every headline from computed facts. Each number in the prose is a registered claim the vetter checks. The same draft is built in two themes below.

The code

import pandas as pd, dstory

df = pd.read_csv("mix.csv")            # year, source, share_pct
d = dstory.draft(df, title="Gas took coal's place", theme="warm-print",
                 source="Illustrative power-mix shares (synthetic data)")
print(d.explain())
dstory.build(d.story, "mix", scenes=d.scenes, vet=True)

# or, with no Python at all:
#   dstory draft mix.csv --theme warm-print --source "Illustrative power-mix shares (synthetic data)"

What explain() said

Profile: 44 rows x 3 columns, long format
  year: temporal (11 distinct, year)
  source: categorical (4 distinct)
  share_pct: measure (19 distinct, averaged when rows repeat)
Scenes:
  1. scene-trend: line-reveal over year x share_pct -- time series detected; share_pct is a share, compared in percentage points, so it follows the largest source in 2024 (Gas)
  2. scene-shift: slope-chart of source, 2014 vs 2024 -- category x first/last period (4 source values present in both)
  3. scene-race: bump-chart of source rank by share_pct -- the top source changed (Coal in 2014, Gas in 2024)
  4. scene-mix: waffle of source by share_pct in 2024 -- share_pct sums to ~100 per year
Claims (6), each checked by the vetter:
  c-trend: Gas share rose 16 points between 2014 and 2024
  c-trend-step: The sharpest move came in 2015, when it rose 6 points from 2014.
  c-shift: Coal share fell 24 points between 2014 and 2024, the biggest shift of any source
  c-shift-contrast: Renewables share, by contrast, rose 8 points.
  c-mix-lead: In 2024, Gas holds the largest share: 43%
  c-mix-next: Renewables is next, at 23%.
